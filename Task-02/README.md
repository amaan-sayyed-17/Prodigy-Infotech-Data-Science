# Prodigy InfoTech Data Science Internship — Task 02

## Titanic Dataset — Data Cleaning and Exploratory Data Analysis

This task uses the official Prodigy InfoTech Task 02 dataset, based on the Titanic dataset from Kaggle.

### Work completed
- Loaded the Titanic training dataset with Pandas.
- Inspected dataset shape and missing values.
- Filled missing `Age` values using the median.
- Filled missing `Embarked` values using the mode.
- Created a `CabinKnown` indicator for cabin availability and removed the original `Cabin` column.
- Saved the cleaned dataset.
- Performed exploratory analysis using survival distribution, survival rate by sex, and passenger class distribution.
- Saved charts and an EDA summary in `outputs/`.
